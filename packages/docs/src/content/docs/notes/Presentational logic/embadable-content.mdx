---
title: "Emebdable content in Arbeidsflate"
---
Embadable content in Arbeidsflate is a feature that allows users to embed external content, such as markdown and html (only legacy content), directly in Arbeidsflate interface, provided
a url to the content and a dialog token.

Content (`text/plain`) adheres to the current version of [CommonMark](https://commonmark.org/) (0.31.2).
For examples of how to use the markdown syntax, see [CommonMark examples](https://spec.commonmark.org/0.31.2/spec.json). With the extension of [GitHub Flavored Markdown](https://github.github.com/gfm/) to support pipe and dash syntax for tables.

Raw HTML inside markdown is passed through the same sanitizing as legacy HTML content, so markdown documents can use the HTML tags listed below for what markdown cannot express, such as forms.

## Process

1. Embedable content is fetched from the provided URL:
   - (For `mainContentReference`) The content is fetched from the URL specified in the `mainContentReference` field of the dialog on loading the dialog details.
   - (For `contentReference` for transmissions) The content is fetched only when the user expands the transmission in the dialog details.
2. The content is sanitized to ensure security and integrity and is transformed into a React component tree:
   - (For Markdown) Transforms markdown into a sanitized, styled React component tree, allowing safe and customizable rendering.
   - (For legacy HTML) Transforms raw HTML into sanitized, styled React components, ensuring safe display of dynamic HTML.
3. The sanitized content is then displayed in the Arbeidsflate interface.

## Request headers

Arbeidsflate sends the same set of headers on every content reference request, both for `mainContentReference` and for `contentReference` on transmissions.

| Header            | Example value                     | Purpose                                                                                                                                                |
| ----------------- | --------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Authorization`   | `Bearer <dialog token>`           | The dialog token issued by Dialogporten for the dialog being viewed. Use it to authorize the request and to identify the end user.                       |
| `Accept-Language` | `en, nb;q=0.9, nn;q=0.8`          | The language the end user has selected in Arbeidsflate, followed by the remaining supported languages (`nb`, `nn`, `en`) with descending q values. Serve the content in the highest ranked language you support. |
| `Prefer`          | `timezone="Europe/Oslo"`          | The end user's IANA time zone, read from the browser (`Intl.DateTimeFormat().resolvedOptions().timeZone`). Format dates and times in the content for this time zone instead of assuming UTC or Norwegian local time. See [RFC 7240](https://datatracker.ietf.org/doc/html/rfc7240). |
| `Content-Type`    | `text/plain`                      | The content type Arbeidsflate expects back.                                                                                                            |

Notes for service owners:

- `Authorization` and `Prefer` are not CORS-safelisted request headers, so the content endpoint must allow them in `Access-Control-Allow-Headers` on the preflight response. A response that only allows `Authorization` will start failing preflight once `Prefer` is sent.
- The response varies by `Accept-Language` and `Prefer`, so set `Vary: Accept-Language, Prefer` if the content is cached.
- The time zone comes from the end user's device and can be any IANA name (for example `America/New_York` for a user abroad), not only `Europe/Oslo`. Fall back to `Europe/Oslo` if the value is missing or unknown to you.
- Arbeidsflate caches the fetched content per dialog and language for the duration of the visit, so expect one request per language the user switches to.

## Restrictions

For security reasons, the content is sanitized and only certain tags are allowed.

### Allowed HTML tags

| HTML Tag                 | Purpose                       | Markdown Equivalent / Example                   |
| ------------------------ | ----------------------------- | ----------------------------------------------- |
| `<p>`                    | Paragraphs                    | Plain text separated by a blank line            |
| `<em>`                   | Italic / emphasis             | `*italic*` or `_italic_`                        |
| `<strong>`               | Bold / strong emphasis        | `**bold**` or `__bold__`                        |
| `<ul>` / `<ol>` / `<li>` | Lists                         | `- item`, `1. item`                             |
| `<a>`                    | Links                         | `[link](https://example.com)`                   |
| `<code>`                 | Inline code                   | `` `inline code` ``                             |
| `<pre><code>`            | Code blocks                   | ```js<br>const x = 1;<br>```                     |
| `<blockquote>`           | Blockquotes                   | `> quoted text`                                 |
| `<hr>`                   | Horizontal rule/separator     | `---` or `***`                                  |
| `<h1>`–`<h6>`            | Headings                      | `# H1`, `## H2`, ..., `###### H6`               |
| `<br>`                   | Line break                    | Line ends with 2+ spaces + Enter                |
| `<table>` / `<thead>` / `<tbody>` / `<tr>` / `<th>` / `<td>` | Tabular data | **Markdown:**<br /><pre>\| Syntax \| Description \|\n\| ----------- \| ----------- \|\n\| Header \| Title \|\n\| Paragraph \| Text \|</pre><br />**HTML:**<br /><pre>&lt;table&gt;\n  &lt;thead&gt;\n    &lt;tr&gt;\n      &lt;th&gt;Syntax&lt;/th&gt;\n      &lt;th&gt;Description&lt;/th&gt;\n    &lt;/tr&gt;\n  &lt;/thead&gt;\n  &lt;tbody&gt;\n    &lt;tr&gt;\n      &lt;td&gt;Header&lt;/td&gt;\n      &lt;td&gt;Title&lt;/td&gt;\n    &lt;/tr&gt;\n    &lt;tr&gt;\n      &lt;td&gt;Paragraph&lt;/td&gt;\n      &lt;td&gt;Text&lt;/td&gt;\n    &lt;/tr&gt;\n  &lt;/tbody&gt;\n&lt;/table&gt;</pre> |
| `<form>` / `<fieldset>` / `<legend>` / `<label>` / `<input>` / `<textarea>` / `<select>` / `<optgroup>` / `<option>` / `<datalist>` / `<button>` / `<output>` | Forms, see [Forms](#forms) | No markdown equivalent, write the form as HTML |

Everything else is removed. Unknown tags are unwrapped and their text kept, while `<script>`, `<style>`, `<iframe>`, `<video>`, `<audio>`, `<object>`, `<embed>`, `<template>`, `<noscript>`, `<svg>` and `<math>` are dropped with their content.

### Allowed attributes

| Tag                                | Attributes                                                                                                                                                         |
| ---------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `<a>`                              | `href` (must be `http`, `https`, `mailto`, `irc`, `ircs` or `xmpp`), `title`                                                                                          |
| `<th>` / `<td>`                    | `align`, `class`, `style`                                                                                                                                            |
| `<table>` / `<thead>` / `<tbody>` / `<tr>` | `class`, `style`                                                                                                                                             |
| `<form>`                           | `action`, `method` (`get` or `post`), `enctype` (`application/x-www-form-urlencoded` or `multipart/form-data`), `novalidate`, `accept-charset`                        |
| `<input>`                          | `type`, `name`, `value`, `checked`, `placeholder`, `required`, `disabled`, `readonly`, `multiple`, `accept`, `min`, `max`, `step`, `minlength`, `maxlength`, `pattern`, `size`, `list`, `autocomplete`, `inputmode` |
| `<textarea>`                       | `name`, `placeholder`, `required`, `disabled`, `readonly`, `minlength`, `maxlength`, `rows`, `cols`, `wrap`, `autocomplete`                                            |
| `<select>`                         | `name`, `required`, `disabled`, `multiple`, `size`, `autocomplete`                                                                                                    |
| `<option>`                         | `value`, `label`, `selected`, `disabled`                                                                                                                             |
| `<optgroup>`                       | `label`, `disabled`                                                                                                                                                  |
| `<button>`                         | `type` (`submit`, `reset` or `button`), `name`, `value`, `disabled`                                                                                                  |
| `<fieldset>`                       | `disabled`, `name`                                                                                                                                                   |
| `<label>`                          | `for`                                                                                                                                                                |
| `<output>`                         | `for`, `name`                                                                                                                                                        |
| All tags                           | `class`, `id`, `lang`, `dir`, `title`, `aria-label`, `aria-labelledby`, `aria-describedby`, `aria-hidden`                                                             |

All other attributes are stripped for security reasons. This includes every event handler attribute (`onclick`, `onfocus` and the like), so content can never run script in Arbeidsflate.

## Forms

Content may contain a form that the end user fills in and submits. The form is rendered with the fields as written, but Arbeidsflate never lets the browser submit it: the submission is intercepted and sent by Arbeidsflate itself, so the user stays in the dialog instead of navigating away from Arbeidsflate.

```html
<form action="https://serviceowner.example/dialogs/1/answers" method="post">
  <fieldset>
    <legend>Bekreft opplysninger</legend>
    <label for="name">Navn</label>
    <input id="name" name="name" type="text" required />
    <label for="county">Fylke</label>
    <select id="county" name="county">
      <option value="03">Oslo</option>
      <option value="11" selected>Rogaland</option>
    </select>
  </fieldset>
  <button type="submit">Send inn</button>
</form>
```

Rules for the form action:

- It must use `https`, and must not contain credentials.
- A relative action is resolved against the URL the content itself was fetched from. A form without an action submits back to that same URL.
- It cannot point at Arbeidsflate's own origin. Such a submission would travel with the end user's session, and is refused.
- `target`, `formaction`, `formmethod`, `formtarget` and `formenctype` are stripped, so the submission always goes to the action on the `<form>` itself.

Rules for the fields:

- `<input type="password">` and `<input type="image">` are not rendered. Arbeidsflate never asks the end user for credentials on behalf of a service owner, and an image input doubles as a submit button and a remote image request.
- `id`, `for`, `list`, `aria-labelledby` and `aria-describedby` are prefixed with `user-content-` so embedded content cannot collide with Arbeidsflate's own markup. Label and field associations written with matching values keep working. Field `name`s are passed through untouched, and are what is submitted.
- `value`, `checked` and `selected` are used as the initial state of a field, and the end user can change them.
